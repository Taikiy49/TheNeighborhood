# Garden redesign — September 23, 2026

Implemented in the connected Studio experience, The Neighborhood (place 111572448337932). This is an environment art pass, not a claim that the full master specification or every game asset is finished.

## Actual changes

- Eight cottages: muted paint palettes, Higgsfield timber siding, steeper navy roofs, cream fascia, attic windows, porch rails, edged stone paths and planted gardens.
- Both shops: finished pitched roofs and gables, framed storefront glazing, revised signs, planters and interior shelving.
- Landscape: 52 textured maple trees, varied placement and scale, softened pavement and road colors, and restrained decorative shadows.
- Interiors: warmer plaster and wood, coordinated cabinets and bedding, shelves, ceramic accessories, rugs and Higgsfield botanical artwork.
- Lighting: afternoon illumination, cooler ambient fill, warm highlights, restrained bloom and atmospheric haze.
- Purchased house paint also recolors the new siding textures.

Architecture, placement and lighting were authored in Studio using `tools/garden-redesign.luau`. The tree was generated by Roblox, not Higgsfield. The result is stylized and still uses simple geometry in some furnishings, vehicles and pets; the interface was not redesigned in this pass.

## Verification

- Final two-client art acceptance: passed; 23 navigation routes, 1,812 decorative parts, 320 siding textures and 104 textured mesh parts. Decorative geometry is anchored and excluded from collision, touch and gameplay queries. Evidence: `garden-navigation-results.json`.
- Eight-client capacity test: passed functional checks for distinct houses, balances, starter kits, eight cars, eight pets and forty rain streaks per client, with no application errors. Mean server frame 16.664 ms, p95 18.095 ms; approximately 2,016 MB server memory. Evidence: `garden-capacity-results.json`.
- Single-player sample: 300 server frames over five seconds; mean 16.665 ms, p95 17.997 ms.
- ContentProvider preloading actual tree MeshPart instances returned Success for both meshes and both texture IDs. Siding and botanical image preloads returned Success.
- Rojo successfully built the portable `.rbxl` from the exported 3,493-instance world and source scripts.
- Final two-client gameplay regression passed with no application errors, including purchases, paint-to-siding consistency, cars, pets, activities, robbery/recovery and disconnect cleanup. Persistence fault tests passed 239 injected requests. Actual Roblox DataStore fixture creation, lock rejection, save/reload, duplicate settlement and release passed; isolated fixtures were removed. Evidence: `garden-core-results.json`.

These are local Studio tests, not a mobile-device benchmark, a production performance certification, or a real-player rejoin test in the public Roblox client. Earlier eight-client runs had substantially worse timing, so this favorable run should not be treated as guaranteed capacity performance.

The redesigned world is saved in source and the portable build. Publishing this art revision and validating it in a public Roblox client are separate release steps. The previous published version was 37; public availability was blocked by Roblox account eligibility requirements.
